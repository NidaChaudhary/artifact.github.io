  • ✓The clean copy is generated in memory

What re-encoding changes

Canvas re-encoding creates a new image file, which avoids carrying over common embedded metadata such as EXIF and GPS fields. It may also remove color profiles, thumbnails, or other file-specific extras.

For sensitive work, verify the downloaded file with a trusted metadata viewer before publishing.
